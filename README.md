# EMI-CALCULATOR
A simple and responsive EMI (Equated Monthly Installment) Calculator built using HTML, CSS, and JavaScript. This project allows users to calculate their monthly loan EMI based on the loan amount, interest rate, and loan tenure.


Features:
1.Calculate monthly EMI instantly
2.Simple and user-friendly interface
3.Responsive design
4.Displays loan amount, interest, tenure, and calculated EMI
5.Built with pure HTML, CSS, and JavaScript
6.Real-time calculation using JavaScript


Technologies Used:
1.HTML5 – Structure
2.CSS3 – Styling and responsive design
3.JavaScript – EMI calculation and functionality


EMI Formula:

EMI = P × R × (1 + R)ⁿ / ((1 + R)ⁿ − 1)

Where:

P = Principal loan amount
R = Monthly interest rate
N = Loan tenure in months

This project was created to practice JavaScript DOM manipulation, event handling, form input handling, and mathematical calculations.
